# Внешняя сортировка txt и csv

Консольная утилита сортирует текстовые файлы, не загружая их в память целиком.
Данные читаются построчно, а промежуточные результаты хранятся во временных файлах.


## Алгоритмы

| Название | Алгоритм |
|---|---|
| `natural` | естественное слияние |
| `balanced` | двухпутевое сбалансированное слияние |
| `nway` | N-путевое слияние |
| `polyphase` | многофазная (Фибоначчиева) сортировка |
| `cascade` | каскадное слияние |

## Запуск

```
python extsortutil.py АЛГОРИТМ ФАЙЛ [ФАЙЛ ...] [параметры]
```

### Параметры

|  |  |
|---|---|
| `АЛГОРИТМ` | один из: `natural`, `balanced`, `nway`, `polyphase`, `cascade` |
| `ФАЙЛ ...` | один или несколько исходных файлов одного формата (`.txt` или `.csv`) |
| `-o`, `--output ФАЙЛ` | выходной файл. Без него каждый файл сортируется на месте. С ним исходные файлы не меняются |
| `-r`, `--reverse` | сортировать по невозрастанию (по умолчанию по неубыванию) |
| `--key КЛЮЧ` | только для csv: имя столбца или его номер (с нуля) |
| `--type {int,float,str}` | тип сортируемых данных: `int` целое, `float` дробное, `str` строка (по умолчанию) |
| `--ways N` | число путей слияния, не меньше 2. Только для `nway` и `cascade`, по умолчанию 3 |
| `--bsize N` | размер блока в строках, хранимого в памяти. Значение по умолчанию задано DEFAULT_BSIZE в common.py|

Если указать несколько файлов вместе с `-o`, данные всех файлов сливаются
в один отсортированный выходной файл. У csv берётся заголовок первого файла.

### Примеры

Отсортировать числа из txt-файла (одно число в строке) по возрастанию:

```
python extsortutil.py natural numbers.txt -o sorted.txt --type int
```

Отсортировать csv по столбцу `age` по убыванию, исходный файл не меняется:

```
python extsortutil.py polyphase people.csv -o out.csv --keys age --type int -r
```

Объединить и отсортировать два csv по дробному столбцу `score`
4-путевым каскадным слиянием:

```
python extsortutil.py cascade a.csv b.csv -o out.csv --key score --type float --ways 4
```

Отсортировать файл на месте (без `-o`) по текстовому столбцу `id`:

```
python extsortutil.py balanced people.csv --key id --type str
```

## Ограничения

- Запись csv должна умещаться на одной строке (перенос строки внутри кавычек не поддерживается).
- Все файлы в одном запуске должны быть одного формата, формат определяется по расширению.
- Размер блока, сортируемого в памяти при получении первых серий, задан
  константой `BLOCK_SIZE` в `common.py` (10 строк по умолчанию, чтобы не загружать небольшие файлы целиком в память).
